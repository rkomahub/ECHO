# Linear three-NV studies

| Directory | Meaning |
|---|---|
| ideal | Instantaneous, independently addressed longitudinal baseline |
| physical/electronic | Electronic spin-1 references and shared-drive gates |
| physical/electron_nitrogen | Intrinsic nitrogen spectra and joint dynamics |
| comparisons | Comparisons between the stated models |
| sensitivity/finite_qubit_controls | Finite pulses and errors in the qubit model |
| sensitivity/effective_noise | Exploratory noise studies; uncalibrated strengths |
| validation | Numerical and approximation checks |

Each study retains the applicable numbered pipeline levels.
Figures remain alongside their generating numerical reports.

The existing gradient_scenario.json is a longitudinal scenario used by
the physical scripts, not a complete physical-model configuration.

Saved reports preserve their original contents, including historical
file paths and software provenance. See migration_manifest.json to
resolve old paths, including saved nuclear checkpoint paths.

Earlier scans remain available; placement here does not certify that
every historical scan is suitable for thesis conclusions.
