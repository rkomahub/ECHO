# Level 1 — Scenario and control objective

## Numerical output

- `scenario_report.json`: original specification, resolved geometry and
  fields, physical parameter records, control objective, assumptions,
  validation results, and software provenance.

## Figures

- `figures/geometry.pdf`: site positions, NV axes, field directions,
  and highlighted target pair.
- `figures/fields.pdf`: laboratory field components and magnitudes
  at each site, with the specified field bound.
- `figures/distances.pdf`: pair separations and the specified minimum
  separation. Distances are calculated from the saved positions.

These outputs describe the scenario. They do not establish coupling
strengths, addressability, gate fidelity, or experimental feasibility.
